How it works

You talk. Claude draws.

There is nothing to draw and no timeline to edit. A reel is a small file Claude writes for you, and everything about it can be changed by asking.

Ask for it

Describe what you want explained. Claude picks the right kind of picture, writes the reel and checks its own render before showing you.

"Make a reel of how our checkout handles a declined card."

Watch and refine

It plays in a pane beside the chat. Point at what you see and say what to change; Claude edits that step and shows it again.

"Shorten this caption, and add a step for the retry."

Share it

Export a video, one image or an image per step, in wide, tall or square. Put it in a post, a doc, a slide or a message.

"Export it as a tall video and a set of stills."

What it makes

Sixteen kinds of reel

From system diagrams to annotated screenshots. Each one builds up a step at a time, with a caption for every step. These are stills from real reels.

Install

Up and running in a few minutes

SwoReel is a plugin for Claude Code. The plugin is all you need. The desktop app is an optional window onto your reels.

Check you have Node and ffmpeg

SwoReel needs Node.js 22.18 or newer to run, and ffmpeg to make video. Images work without ffmpeg.

# macOS
brew install node ffmpeg

# Windows
winget install OpenJS.NodeJS Gyan.FFmpeg

# Linux: use your package manager, for example
sudo apt install nodejs ffmpeg

Add the plugin to Claude Code

Run these two commands inside Claude Code. The first tells it where SwoReel lives; the second installs it.

/plugin marketplace add tomswokowski/sworeel
/plugin install sworeel@tomswokowski

Then ask for a reel: "make a reel of how a request reaches the database." Type /sworeel any time to browse and play what you have made.

Get the desktop app optional

A window for browsing, playing, organising and exporting your reels. It works with the plugin from the step above, so install that first.

macOS Your system

Download .dmg

Open the file and drag SwoReel to Applications. One download for Apple silicon and Intel Macs.

Windows Your system

Download .exe.msi

The installer is not signed yet, so Windows shows a warning. Choose More info, then Run anyway.

Linux Your system

AppImage.deb.rpm

The AppImage runs on any distribution: make it executable with chmod +x and open it.

Downloads come from the latest release on GitHub.

Set up

Nothing to configure. Plenty you can change.

The app finds the plugin on its own and opens on your library. Every setting below is shared between the app and Claude, so you can flip a switch in Settings or just ask.

Your creditA small watermark, such as your handle, in the corner of everything you export. "Put @me on my exports."
Your coloursReels are drawn in ten colours you can change, for every reel or just one. "Make my reels match our brand: navy and orange, light background."
Your preferencesTell Claude once how you like things and it keeps to it. "Always keep captions under ten words."
Default formatsWhich shapes "export it" makes: wide (16:9), tall (9:16), square (1:1), or several at once.
Frame rate and step dots24, 30 or 60 frames a second for video, and whether a row of progress dots is drawn on each frame.
Where files goExports land in Documents/SwoReel. Your reels live with the app's data. Both can be moved.
Follow ClaudeA switch in the app that keeps it on whichever reel Claude changed last, so you watch edits happen.
Do I need the desktop app?

No. Everything works from Claude Code: making reels, playing them beside the chat, exporting and organising. The app is for when you would like a window with thumbnails, a scrubber and drag and drop.

The app says it cannot find the sworeel command

That command comes with the plugin, so install the plugin in Claude Code first, then start the app again. If Node.js is missing or older than 22.18, the command cannot start; install or update it.

How do I move my reels to another computer?

In the app, open Settings and choose Export All Reels, or ask Claude to bundle them. You get one .sworeel file holding your reels and their pictures. Import it on the other computer. Nothing already there is replaced.

How do I update?

The plugin updates through Claude Code: /plugin update sworeel@tomswokowski. For the app, download the newest version from this page and install it over the old one. Your reels and settings are kept.
